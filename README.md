# Telhado Verde - Client

Projeto front-end desenvolvido com React e Vite.

## Pré-requisitos

* Node.js (versão 18 ou superior)
* npm (ou gerenciador de pacotes de sua preferência)

## Passo a passo para execução

1. Instale as dependências:

>>> npm install


2. Configure as variáveis de ambiente:
Crie um arquivo `.env` na raiz do projeto e adicione a configuração da API:

VITE_API_URL=http://localhost:8000

3. Inicie o servidor de desenvolvimento:

>>> npm run dev

4. Acesse a aplicação no navegador através do endereço exibido no terminal (padrão: `http://localhost:5173`).
